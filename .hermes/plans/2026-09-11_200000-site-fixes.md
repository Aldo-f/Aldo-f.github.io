# Plan: Fix Aldo-f.github.io Site Issues

## Goal
Fix missing page content, blog post excerpts, duplicate Dutch posts in English, nav "Index" labels, and add language-aware chat widget text.

## Root Causes Identified

1. **Missing content (thuis, blanky-v1, etc.)**: The multirepo plugin imports docs but the content appears empty. The skill note says "Multirepo plugin fails cleanup of `docs/temp_dir` on build errors" — need to check if temp dir exists after build and inspect the actual imported content.

2. **Missing content (index, about)**: Material theme `navigation.indexes` + `section-index` plugin converts first-child pages to SectionPage, stripping markdown content. Fix: ensure frontmatter titles differ from section titles OR remove `section-index` from affected sections.

3. **Blog "Continue reading" without word limit**: No `excerpt_separator` configured in blog plugin settings. Need to add it.

4. **Dutch blog posts visible in English section**: Files `einde-scrum.md` and `start-scrumweek.md` exist identically in both `docs/en/blog/posts/` and `docs/nl/blog/posts/`. The `autotranslate` plugin is `mode: report` only — it doesn't create translations. Need to either translate them or remove from en.

5. **Dutch left menu shows "Index" for blog**: `navigation.indexes` feature shows "Index" for `blog/index.md`. Fix: rename `blog/index.md` to `blog.md` (already exists) and update nav.

6. **Chat widget not language-aware**: Placeholder and title hardcoded in English. Need to detect current language from page URL (`/nl/` prefix) and switch text.

## Architecture / Approach

- All fixes are in `mkdocs.en.yml`, `mkdocs.nl.yml`, `mkdocs.base.yml`, `hooks/chat.py`, and blog post files.
- The multirepo import issue needs investigation — check if docs are actually being cloned and what's in the temp dir.
- Blog excerpt control via `excerpt_separator` in blog plugin config.
- Language detection in chat widget via `window.location.pathname` check for `/nl/` prefix.

## Risks, Tradeoffs, and Open Questions

1. **Multirepo import may still fail**: If the network/DNS prevents cloning, the imported docs will remain empty. Workaround: clone repos manually into `docs/<project>/` and update nav refs.
2. **Removing `navigation.indexes`**: This may affect other first-child pages. Verify all pages have proper titles.
3. **Blog excerpt separator**: Setting `excerpt_separator: ""` may show full content instead of truncated. Alternative: use `<hr>` or `<!-- more -->` in posts.
4. **Dutch posts in English**: If these posts should be available in both languages, consider adding proper English translations instead of deleting.
5. **Chat widget language detection**: Current approach uses URL prefix check. This works but may break if URLs change. Alternative: use `document.documentElement.lang` attribute.
