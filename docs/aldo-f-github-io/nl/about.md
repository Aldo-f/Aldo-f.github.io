# Over deze site

Dit is de centrale documentatie-hub van de projecten van Aldo Fieuw. Ze bundelt
documentatie uit verschillende repositories, die tijdens de build rechtstreeks
uit de bron wordt opgehaald — zodat ze altijd klopt met de code.

## Hoe de documentatie is ingedeeld

| Sectie | Bron | Opmerkingen |
|--------|------|-------------|
| **Clock** | [`Aldo-f/clock`](https://github.com/Aldo-f/clock) (`main`) | Speciale klokken — features en ontwikkelingsdocumentatie |
| **Thuis main** | [`Aldo-f/thuis`](https://github.com/Aldo-f/thuis) (`main`) | Actuele MkDocs-documentatie (EN + NL) |
| **Thuis v5** | `thuis` branch `v5/main` | Quickstart, API, architectuur |
| **Thuis v4** | `thuis` tag `v4.1.0` | Installatie, gebruik, referenties |
| **Thuis v3** | `thuis` tag `v3.0.0` | Legacy Python-versie (MkDocs, EN + NL) |
| **Radio Community** | lokaal project, gespiegeld tijdens de build | Architectuur, API, streaming |
