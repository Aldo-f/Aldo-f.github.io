# WZC Sint-Antonius — Client Briefing (English reference)

Original: Dutch intake notes from management, **21/08/2026**. Translated for project
reference. The Dutch original remains the source of truth for any wording disputes.

## Brand & tone

- **Keep the existing logo and colours** (teal `#60A3A0` from the logo).
- **Warm atmosphere** — the site must feel like a home, not an institution.
- **Speak more through imagery** ("meer spreken met beeld") — photo-driven pages.
- Put **"living and life" central**, *not* "care" — frame everything around daily life.
- Reference site for features/feel: **https://armonea.be/**

## Audience

- Primary: **children and grandchildren** of (future) residents, plus **job applicants**.
- What visitors look at most today: **prices and what is included**.

## Site structure & features

| Page / feature | Requirement |
|---|---|
| Home | Warm, image-led, mobile-first |
| Living & Life | Central concept page |
| Prices | Clear tariffs **and what is included** |
| Rooms | Show rooms, ideally floor plans — "an idea of where you'd end up" |
| Activities | Activity reports afterwards with photos, "a bit like Facebook"; link to FB but **no RSS feed embed** on the site |
| Gallery | Photos of residents |
| History | Its own page — those who want to read it will find it |
| Mission & Vision | Separate page — texts supplied **next year** |
| Palliative & dementia care | Separate page with our vision on it |
| Testimonials | From staff **and** residents |
| FAQ | Yes |
| Contact | Not dry/cold — warmer, ideally with a photo of the social-service person you end up with; Google Maps location "under the church tower — heart of the WZC" |

## Technical & compliance

- **Mobile-first, mobile-friendly — hard requirement.**
- **GDPR**: privacy policy + consent needed because there will be a contact form (there isn't one now).
- **SEO**: must be findable on many keywords; grow online visibility.
- Check **adjusted font size / contrast** (accessibility for older readers).

## Editing & governance

- Max **3 people** should be able to add/edit things — **non-technical people**.
- Back end must be **simple and friendly**: edit menus, add posts, edit all texts,
  add photos, adjust prices…
- **Texts will be supplied by the client.**
- Photos may be taken by us, but they have someone who loves taking good photos —
  put professional photography as an **optional line item in the quote**.
- **Quality over deadline** ("if we're changing it, let's do it right straight away").
- **Annual maintenance contract** afterwards for updates, invoiced yearly.

## Features worth adopting from armonea.be

- Audience-first homepage cards per living type (WZC / assistentiewoning / kortverblijf…)
- Big warm photography on every block; quote/testimonial carousel
- "What makes the difference every day" blocks (meals, family contact, pets welcome)
- Jobs/recruitment teaser section (our audience includes applicants)
- Values section; clear consent checkbox on contact forms (GDPR)
