This is the first post on the new blog section of the documentation hub.
Short notes, release announcements and write-ups that do not belong to a
single project's manual will live here from now on.

<!-- more -->

Publishing here is deliberately simple: one markdown file with a title and a
date is enough. Expect irregular but honest updates about the projects on this
hub — including the quirky ones, like the xylophone-framework experiment that
started as a weekend joke and somehow keeps growing.
